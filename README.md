# Local SEO Analyzer

## Objective
The Local SEO Analyzer is a Python-based application that analyzes the local SEO performance of a business and generates a detailed Excel report with recommendations for improvement.

## Features
- Google Business Profile Analysis
- Website SEO Analysis
- Local SEO Analysis
- SEO Score Calculation
- Excel Report Generation
- SEO Recommendations

## Technologies Used
- Python
- Requests
- BeautifulSoup
- OpenPyXL

## Installation

Install the required libraries:

```bash
pip install -r requirements.txt
```

## Run the Project

```bash
python3 main.py
```

## Output

The application generates:
- Business Information
- Website SEO Audit
- Local SEO Audit
- SEO Score (Out of 100)
- Recommendations
- Excel Report (`SEO_Report.xlsx`)
